@page guide_maintenance 8. 文档维护

需要修改代码或新增文档时阅读本章。每个专题保留稳定 page id 和唯一导航父节点；跨模块阅读用引用链接，让目录持续保持清晰。

1. @subpage documentation_rules "随代码更新文档"：从实际 diff 判断受影响流程、算法、配置与接口，补充源码证据并运行检查。
2. @subpage documentation_structure "章节结构与导航规则"：理解章节导览、专题归属、来源目录及无环导航约束。

编辑文档源码后，重新运行文档生成和链接检查，再刷新本地页面。HTML、导航脚本和关系图由 Doxygen 生成。
