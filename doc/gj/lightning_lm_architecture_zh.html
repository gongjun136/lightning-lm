Lightning-LM 激光建图与定位架构

基于 ROS2 / C++17 的完整 3D LiDAR SLAM 与定位框架：在线/离线运行入口、LIO 前端、回环优化、2.5D 栅格地图、分块地图与高频 TF 输出。

运行入口

  • • 建图：`run_slam_online` 订阅传感器；`run_slam_offline` 遍历 ROS2 bag。
  • • 定位：`run_loc_online/offline` 读取地图路径并输出 TF。
  • • 调试：前端、回环和 UI 有独立可执行程序。

核心链路

  • • LIO 负责点云预处理、IMU 同步、ESKF 状态估计和 IVox 局部地图。
  • • 回环模块基于关键帧做候选检测，并用 miao 进行 SE3 位姿图优化。
  • • 定位模块复用 LIO 预测，结合 LidarLoc、PGO、平滑器和外推器。

地图与输出

  • • 建图结果包含 3D PCD、分块地图、动态/静态层和可选 2D 栅格图。
  • • `TiledMap` 支持大场景邻近加载和动态图层策略。
  • • `/lightning/save_map` 是已注册建图服务；`LocCmd.srv` 是定位命令接口定义。
