> 在符号说明前需要清楚 点、向量、坐标系、坐标之间的关系：
>
> **点**表示“位置”；**向量**是一个平移量，只要方向和长度相同，放在哪里都表示同一个自由向量；**坐标系**是一套“描述规则”；**坐标**是在某个坐标系下，对点或向量的数字表示。
>
> 关系可以总结为：
>
> ```
> 几何对象：点、向量
> 描述工具：坐标系
> 数字表达：坐标
> ```
>
> 更具体地说：
>
> ```
> 点 + 坐标系 -> 点的坐标
> 向量 + 坐标系 -> 向量的坐标
> 两个点相减 -> 向量
> 点加向量 -> 新的点
> ```

# 符号说明

本文只统一会影响推导方向、坐标表达、扰动定义和滤波含义的关键符号。具体算法中的局部变量，如某个残差、特征点、地图点、鲁棒权重等，在对应章节中单独说明。

| 类别 | 符号 | 说明 |
| :--- | :--- | :--- |
| 基本约定 | $a,b,c$ | 标量 |
| 基本约定 | $p,q,o_a$ | 点，小写斜体；$o_a$ 表示坐标系 $\mathcal{F}_a$ 的原点。点是几何对象，不是坐标列向量 |
| 基本约定 | $\mathbf{a},\mathbf{b},\mathbf{c}$ | 向量，小写黑体 |
| 基本约定 | $\mathbf{A},\mathbf{B},\mathbf{C}$ | 矩阵，大写黑体 |
| 坐标系 | $\mathcal{F}_a=\{o_a,\mathbf{i}_a,\mathbf{j}_a,\mathbf{k}_a\}$ | 坐标系，由原点和三根单位正交基向量组成 |
| 坐标系 | $\mathcal{F}_w,\mathcal{F}_b,\mathcal{F}_i,\mathcal{F}_l,\mathcal{F}_c,\mathcal{F}_r,\mathcal{F}_E$ | 常用坐标系，分别表示世界/局部地图系、车体/载体系、IMU 系、LiDAR 系、相机系、GNSS 接收器系、ECEF 系 |
| 坐标表达 | ${}^{a}\mathbf{p}={}^{a}\mathbf{p}_{ap}$ | 点 $p$ 在坐标系 $\mathcal{F}_a$ 下的坐标列向量；右下标 $ap$ 表示从 $o_a$ 指向点 $p$，上下文清楚时可简写为 ${}^{a}\mathbf{p}$ |
| 坐标表达 | ${}^{a}\mathbf{v}$ 或 ${}^{a}\mathbf{v}_{pq}$ | 向量在坐标系 $\mathcal{F}_a$ 下的坐标表达；${}^{a}\mathbf{v}_{pq}={}^{a}\mathbf{q}-{}^{a}\mathbf{p}$ 表示从点 $p$ 指向点 $q$ 的位移向量 |
| 坐标表达 | $\mathbf{i}_a,\mathbf{j}_a,\mathbf{k}_a$ | 坐标系 $\mathcal{F}_a$ 的 x、y、z 轴单位向量；默认在世界系下表达，必要时写作 ${}^{b}\mathbf{i}_a,{}^{b}\mathbf{j}_a,{}^{b}\mathbf{k}_a$ |
| 坐标变换 | $\mathbf{R}_{ab}$ | 从坐标系 $\mathcal{F}_b$ 到坐标系 $\mathcal{F}_a$ 的旋转矩阵，满足 ${}^{a}\mathbf{v}=\mathbf{R}_{ab}{}^{b}\mathbf{v}$ |
| 坐标变换 | ${}^{a}\mathbf{t}_{ab}$ | 从 $o_a$ 指向 $o_b$ 的平移向量，在坐标系 $\mathcal{F}_a$ 下表达 |
| 坐标变换 | $\mathbf{T}_{ab}=(\mathbf{R}_{ab},{}^{a}\mathbf{t}_{ab})$ | 从坐标系 $\mathcal{F}_b$ 到坐标系 $\mathcal{F}_a$ 的位姿变换 |
| 坐标变换 | ${}^{a}\mathbf{p}_{ap}=\mathbf{R}_{ab}{}^{b}\mathbf{p}_{bp}+{}^{a}\mathbf{t}_{ab}$ | 点坐标从 $\mathcal{F}_b$ 变换到 $\mathcal{F}_a$；含义是“从 $o_a$ 到 $p$ = 从 $o_a$ 到 $o_b$ + 从 $o_b$ 到 $p$” |
| 坐标变换 | $\mathbf{T}_{ba}=\mathbf{T}_{ab}^{-1}$，$\mathbf{T}_{ac}=\mathbf{T}_{ab}\mathbf{T}_{bc}$ | 位姿逆变换和位姿复合 |
| 李群扰动 | $\operatorname{SO}(3),\mathfrak{so}(3)$ | 三维旋转李群及其李代数 |
| 李群扰动 | $\operatorname{SE}(3),\mathfrak{se}(3)$ | 三维刚体变换李群及其李代数 |
| 李群扰动 | $\boldsymbol{\phi},\delta\boldsymbol{\theta}$ | 旋转向量/小角度扰动向量；在 ESKF 中 $\delta\boldsymbol{\theta}$ 常表示姿态误差 |
| 李群扰动 | $[\boldsymbol{\phi}]_\times$，$(\cdot)^\wedge$，$(\cdot)^\vee$ | 叉乘矩阵、向量到李代数矩阵、李代数矩阵到向量的操作 |
| 李群扰动 | $\operatorname{Exp}(\boldsymbol{\phi})$，$\operatorname{Log}(\mathbf{R})$ | 向量形式的指数映射和对数映射 |
| 李群扰动 | $\boxplus,\boxminus$ | 广义加法/减法。本文默认旋转采用右扰动：$\mathbf{R}\boxplus\delta\boldsymbol{\theta}=\mathbf{R}\operatorname{Exp}(\delta\boldsymbol{\theta})$，$\mathbf{R}_1\boxminus\mathbf{R}_2=\operatorname{Log}(\mathbf{R}_2^\mathsf{T}\mathbf{R}_1)$ |
| 李群扰动 | $\mathbf{J}_l,\mathbf{J}_r$ | $\operatorname{SO}(3)$ 的左/右雅可比；只在需要把李群乘法扰动和李代数加法扰动互相转换时使用 |
| 索引 | 下标 $k$ | 离散时间索引，第 $k$ 个时刻 |
| 索引 | 下标 $j$ | 当前时刻的第 $j$ 个观测或数据点 |
| 索引 | 上标 $-$，上标 $+$ | 先验和后验 |
| 索引 | 上标 $\kappa$ | 同一时刻内的观测迭代索引 |
| 状态 | $\mathbf{x}_k$，$\hat{\mathbf{x}}_k$，$\tilde{\mathbf{x}}_k$ | 真值状态、名义状态、误差状态 |
| 状态 | $\mathbf{x}_k=\hat{\mathbf{x}}_k\boxplus\tilde{\mathbf{x}}_k$ | 真值状态、名义状态和误差状态之间的关系 |
| 状态 | ${}^{w}\mathbf{p},{}^{w}\mathbf{v},\mathbf{R}_{wi}$ | 位置、速度和 IMU 到世界系的姿态；必要时用完整下标说明具体原点，如 ${}^{w}\mathbf{p}_{wi}$ |
| 状态 | ${}^{i}\mathbf{b}_g,{}^{i}\mathbf{b}_a,{}^{w}\mathbf{g}$ | 陀螺零偏、加速度计零偏、重力向量 |
| 概率量 | $\boldsymbol{\mu}_k,\tilde{\boldsymbol{\mu}}_k$ | 状态均值和误差状态均值 |
| 概率量 | $\mathbf{P}_k,\tilde{\mathbf{P}}_k$ | 状态协方差和误差状态协方差 |
| 模型 | $\mathbf{u}_k$ | 控制/输入向量，如 IMU 量测 |
| 模型 | $\mathbf{z}_k$，$\mathbf{h}(\mathbf{x}_k)$ | 观测向量和观测模型 |
| 模型 | $\mathbf{r}_k$ | 观测残差。本文默认 $\mathbf{r}_k=\mathbf{h}(\mathbf{x}_k)-\mathbf{z}_k$；若某处采用相反定义，残差和雅可比需同步变号 |
| 模型 | $\mathbf{F}_k,\mathbf{H}_k,\mathbf{K}_k$ | 状态/误差传播雅可比、观测雅可比、卡尔曼增益；若需区分误差状态和噪声雅可比，再写作 $\mathbf{F}_{\tilde{x},k},\mathbf{F}_{\eta,k}$ |
| 噪声 | $\mathbf{w}_k,\mathbf{W}_k$ | 过程噪声及其协方差 |
| 噪声 | $\mathbf{n}_k,\mathbf{N}_k$ | 观测噪声及其协方差 |
| 噪声 | $\boldsymbol{\eta}_k$ | IMU 或过程模型中的噪声向量，常包含陀螺噪声、加速度计噪声和零偏随机游走噪声 |
