> 在符号说明前需要清楚 点、向量、坐标系、坐标之间的关系：
>
> **点**表示“位置”；**向量**是一个平移量，只要方向和长度相同，放在哪里都表示同一个自由向量；**坐标系**是一套“描述规则”；**坐标**是在某个坐标系下，对点或向量的数字表示。
>
> 关系可以总结为：
>
> ```
> 几何对象：点、向量 
> 描述工具：坐标系 
> 数字表达：坐标
> ```
>
> 更具体地说：
>
> ```
> 点 + 坐标系 -> 点的坐标 
> 向量 + 坐标系 -> 向量的坐标 
> 两个点相减 -> 向量 
> 点加向量 -> 新的点
> ```

# 符号说明

| 类别         | 符号                                                         | 说明                                                         |
| :----------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| 基本符号     | $a, b, c$                                                    | 标量                                                         |
| 基本符号     | $p, q, o_a$                                                  | 点，小写斜体；$o_a$ 表示坐标系 $\mathcal{F}_a$ 的原点。点是几何对象，不是坐标列向量 |
| 基本符号     | $\mathbf{a}, \mathbf{b}, \mathbf{c}$                         | 向量，小写黑体；向量表示位移、方向、速度等量                 |
| 基本符号     | $\mathbf{A}, \mathbf{B}, \mathbf{C}$                         | 矩阵，大写黑体                                               |
| 基本符号     | $\mathcal{F}_a=\{o_a,\mathbf{i}_a,\mathbf{j}_a,\mathbf{k}_a\}$ | 坐标系，由原点 $o_a$ 和三根基向量组成；$\mathcal{F}_E, \mathcal{F}_w, \mathcal{F}_i, \mathcal{F}_l, \mathcal{F}_r$ 分别表示 ECEF、局部世界系、IMU 坐标系、LiDAR 坐标系、GNSS 接收器坐标系 |
| 基本符号     | $\mathbf{i}_{a}$                                             | 坐标系 $\mathcal{F}_a$ 的 x 轴单位向量，默认在世界系 $\mathcal{F}_w$ 下表达；若需强调其他表达坐标系，写作 ${}^{b}\mathbf{i}_{a}$ |
| 基本符号     | $\mathbf{j}_{a}$                                             | 坐标系 $\mathcal{F}_a$ 的 y 轴单位向量，默认在世界系 $\mathcal{F}_w$ 下表达；若需强调其他表达坐标系，写作 ${}^{b}\mathbf{j}_{a}$ |
| 基本符号     | $\mathbf{k}_{a}$                                             | 坐标系 $\mathcal{F}_a$ 的 z 轴单位向量，默认在世界系 $\mathcal{F}_w$ 下表达；若需强调其他表达坐标系，写作 ${}^{b}\mathbf{k}_{a}$ |
| 基本符号     | ${}^{a}\mathbf{p}={}^{a}\mathbf{p}_{ap}=\begin{bmatrix}{}^{a}p_x&{}^{a}p_y&{}^{a}p_z\end{bmatrix}^{T}$ | 点 $p$ 在坐标系 $\mathcal{F}_a$ 下的坐标列向量。完整写法为 ${}^{a}\mathbf{p}_{ap}$，右下标 $ap$ 表示从坐标系原点 $o_a$ 指向点 $p$；简写为 ${}^{a}\mathbf{p}$。若点用观测索引 $j$ 表示，完整写法可写成 ${}^{a}\mathbf{p}_{aj}$，右下标 $aj$ 表示从 $o_a$ 指向第 $j$ 个点，不再写成 ${}^{a}\mathbf{p}_{ap_j}$；若点名本身为 $q_j$，则可写成 ${}^{a}\mathbf{q}_{aq_j}$。${}^{a}p_x,{}^{a}p_y,{}^{a}p_z$ 是它在 $\mathcal{F}_a$ 的 x、y、z 轴分量，也可以通过$\left[{}^{a}\mathbf{p}\right]_x$从点坐标 ${}^{a}\mathbf{p}$ 中取 x 分量；y、z 分量同理 |
| 基本符号     | ${}^{a}\mathbf{v}$ 或 ${}^{a}\mathbf{v}_{pq}$                | 向量 $\mathbf{v}$ 在坐标系 $\mathcal{F}_a$ 下的坐标表达；若需说明起点和终点，完整写作 ${}^{a}\mathbf{v}_{pq}$，表示从点 $p$ 指向点 $q$ 的位移向量的坐标，且 ${}^{a}\mathbf{v}_{pq}={}^{a}\mathbf{q}-{}^{a}\mathbf{p}$ |
| 坐标变换     | $\mathbf{R}_{ab}$                                            | 从坐标系 $\mathcal{F}_b$ 到坐标系 $\mathcal{F}_a$ 的旋转矩阵，可把 $\mathcal{F}_b$ 中表达的坐标变换到 $\mathcal{F}_a$ 中表达，即 ${}^{a}\mathbf{v} = \mathbf{R}_{ab}\,{}^{b}\mathbf{v}$ |
| 坐标变换     | ${}^{a}\mathbf{t}_{ab}$                                      | 变换矩阵 $\mathbf{T}_{ab}$ 的平移项，表示从 $o_a$ 指向 $o_b$ 的向量，在坐标系 $\mathcal{F}_a$ 下坐标表达 |
| 坐标变换     | $\mathbf{T}_{ab} = \left(\mathbf{R}_{ab}, {}^{a}\mathbf{t}_{ab}\right)$ | 从坐标系 $\mathcal{F}_b$ 到坐标系 $\mathcal{F}_a$ 的位姿变换矩阵，由旋转矩阵和平移向量组成 |
| 坐标变换     | ${}^{a}\mathbf{p}_{ap}=\mathbf{R}_{ab}\,{}^{b}\mathbf{p}_{bp}+{}^{a}\mathbf{t}_{ab}$，简写为 ${}^{a}\mathbf{p}=\mathbf{R}_{ab}\,{}^{b}\mathbf{p}+{}^{a}\mathbf{t}_{ab}$ | 点 $p$ 的坐标从 $\mathcal{F}_b$ 变换到 $\mathcal{F}_a$。右下标 $ap$ 表示从 $o_a$ 指向点 $p$，$bp$ 表示从 $o_b$ 指向点 $p$，$ab$ 表示从 $o_a$ 指向 $o_b$；含义是“从 $o_a$ 到 $p$ = 从 $o_a$ 到 $o_b$ + 从 $o_b$ 到 $p$”，其中 ${}^{b}\mathbf{p}_{bp}$ 需先通过 $\mathbf{R}_{ab}$ 旋转到 $\mathcal{F}_a$ 下表达 |
| 坐标变换     | $\boxplus$                                                   | 旋转的广义加法，$\mathbf{R} \boxplus \delta\boldsymbol{\theta}= \mathbf{R}\operatorname{Exp}(\delta\boldsymbol{\theta})$ |
| 坐标变换     | $\boxminus$                                                  | 旋转的广义减法，$\mathbf{R}_1 \boxminus \mathbf{R}_2= \operatorname{Log}(\mathbf{R}_2^\mathsf{T}\mathbf{R}_1)$ |
| 索引与上下标 | 下标 $k$                                                     | 离散时间索引，第 $k$ 个时刻                                  |
| 索引与上下标 | 上标 $\kappa$                                                | 时刻 $k$ 内部的观测迭代索引，$\kappa = 0, 1, \ldots, K_k - 1$；可与 $-$、$+$ 组合为 $\kappa-$、$\kappa+$，分别表示第 $\kappa$ 次观测迭代中的局部先验和局部后验 |
| 索引与上下标 | 下标 $j$                                                     | 时刻 $k$ 的第 $j$ 个观测点（如激光雷达点），$j = 1, \ldots, J_k$ |
| 索引与上下标 | 上标 $-$                                                     | 预测（先验）：尚未融合当前时刻观测之前的量                   |
| 索引与上下标 | 上标 $+$                                                     | 更新（后验）：观测迭代收敛后得到的量                         |
| 李群与李代数 | $\operatorname{SO}(3)$                                       | 三维旋转李群，元素为旋转矩阵 $\mathbf{R}$                    |

| 李群与李代数 | $\boldsymbol{\phi}, \delta\boldsymbol{\theta}$               | 旋转向量/小角度扰动向量，属于 $\mathbb{R}^3$；在 ESKF 中 $\delta\boldsymbol{\theta}$ 常表示姿态误差 |
| 李群与李代数 | $[\boldsymbol{\phi}]_{\times}$                               | 向量 $\boldsymbol{\phi}$ 对应的叉乘矩阵，也称反对称矩阵，满足 $[\boldsymbol{\phi}]_{\times}\mathbf{v}=\boldsymbol{\phi}\times\mathbf{v}$ |
| 李群与李代数 | $(\cdot)^{\vee}$                                             | 叉乘矩阵的逆操作，把反对称矩阵还原为向量，即 $([\boldsymbol{\phi}]_{\times})^\vee=\boldsymbol{\phi}$ |
| 李群与李代数 | $\exp([\boldsymbol{\phi}]_{\times})$                         | 矩阵指数映射，从李代数矩阵 $[\boldsymbol{\phi}]_{\times}\in\mathfrak{so}(3)$ 到李群 $\operatorname{SO}(3)$ |
| 李群与李代数 | $\log(\mathbf{R})=[\boldsymbol{\phi}]_{\times}$              | 矩阵对数映射，从李群 $\mathbf{R}\in\operatorname{SO}(3)$ 到李代数矩阵 $\log(\mathbf{R})\in\mathfrak{so}(3)$，结果写成反对称矩阵形式 |
